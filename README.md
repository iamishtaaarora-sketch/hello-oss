## 🎯 The mission

Add yourself to [MEMBERS.md](MEMBERS.md) through a pull request. It takes about five minutes and at the end of it you have a real contribution on your GitHub profile.

## 🛤 Pick your path

### Path A: Browser only (zero install)

1. Open [MEMBERS.md](MEMBERS.md) and click the **pencil icon** (top right of the file)
2. GitHub will offer to fork the repo for you. Accept.
3. Add your line at the bottom, following the format already in the file
4. Scroll down, write a short commit message, click **Propose changes**
5. Click **Create pull request**. Done.

### Path B: Terminal (the real workflow)

```bash
# 1. Fork this repo using the Fork button on GitHub, then:
git clone https://github.com/YOUR-USERNAME/hello-oss.git
cd hello-oss

# 2. Make a branch
git checkout -b add-my-name

# 3. Edit MEMBERS.md, add your line, then:
git add MEMBERS.md
git commit -m "Add YOUR-NAME to members"
git push -u origin add-my-name
```

Then open GitHub, and it will show a banner offering to open a pull request. Click it, write one line about yourself, submit.
