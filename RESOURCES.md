# 📚 Resources

Links the group actually found useful. Add yours through a PR, one line, with a word on why it is worth clicking.

## Git and GitHub

- [Oh Shit, Git!?!](https://ohshitgit.com/) - what to type when you have broken something and are panicking
- [Learn Git Branching](https://learngitbranching.js.org/) - visual, interactive, weirdly fun
- [GitHub Skills](https://skills.github.com/) - official hands-on courses that run inside real repos

## Finding stuff to contribute to

- [good first issue](https://goodfirstissue.dev/) - aggregates beginner-friendly issues across popular repos
- [Up For Grabs](https://up-for-grabs.net/) - projects that explicitly want new contributors

## Reading

- [How to Contribute to Open Source](https://opensource.guide/how-to-contribute/) - the guide everything else copies
